📲 Install guide

Install Jessica on your phone or laptop in under a minute

⏱️ One minute · updated November 2026

Jessica is not an app you download from a store. It is a web app you install from the browser itself: nothing to wait for, no account, no big download. After installing it opens like any other app, and it keeps working offline.

🤖 Android 📱 iPhone 💻 Desktop ✅ After installing 🛠️ If it is missing

Before you start — three small things

1) Open the link in a real browser, not inside Facebook or WhatsApp. If it opened there, tap the menu and choose “Open in browser”.
2) Make sure the link starts with https — the browser only installs secure pages.
3) Let the page finish loading before you press install.

🤖 Android

Chrome or Samsung Internet

  1. Open is.gd/jessicaapp in Chrome.
  2. Wait until the page loads fully (five to ten seconds on normal internet).
  3. Tap the three-dot menu at the top right.
  4. Choose Install app, or Add to Home screen if that is what you see.
  5. Confirm. The icon lands on your home screen and opens full screen, without the browser bar.
💡 No install option? Update Chrome from the Play Store, or use Add to Home screen — the result is the same.

📱 iPhone and iPad

iPhone does not show an install button inside Safari the way Android does, but the share sheet does the same job.

Safari on iPhone and iPad

  1. Open the link in Safari specifically. Any other browser on iPhone, including Chrome, cannot install it.
  2. Tap the share button (the square with the arrow pointing up) at the bottom of the screen.
  3. Scroll down and choose Add to Home Screen.
  4. Type the name “Jessica” and press Add.
💡 iOS keeps site data as long as you do not clear Safari data, so your child's progress stays where it is.

💻 Computer

Chrome or Edge on a laptop

  1. Open the link in Chrome or Edge.
  2. Press the small install icon (a screen with an arrow) on the right of the address bar.
  3. Press Install.
  4. The app opens in its own window and gets a desktop shortcut.
💡 If the icon is hidden, open the browser menu and choose “Install Jessica”.

If the install option is missing or does not work

No install button on Android?

Make sure you opened it on https in Chrome and not inside another app's browser. Try the three-dot menu → Add to Home screen; it does the same job.

The icon opens in the browser instead of its own window?

That means it was added as a shortcut, not installed. Remove the shortcut, reopen the link in Chrome, wait a second longer and press Install app.

iPhone does not offer Add to Home Screen?

Safari is required. If you came from Facebook, tap the menu and choose Open in Safari first.

The app will not open offline?

Open it once while connected and let the pages you need download. Then switch the internet off and try again.

I cleared browser data — is everything gone?

Progress, books and cards are stored locally, so clearing site data removes them. Clear other sites only, and avoid “clear all data”.

Can I install it on more than one device?

Yes, each device installs separately and keeps its own progress. There is no cross-device sync because there is no account and no server.
