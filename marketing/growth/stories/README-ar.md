## إزاي تنشر ستوري
فيسبوك → **Create story** → **Create a photo or video story** → اختار ملف `.jpg` → Share to story.

> استخدم **JPG** مش PNG: فيسبوك رفض الـPNG في الاختبار («file format»)، والـJPG اشتغل.

## إزاي تضيف يوم جديد
افتح `story.html`، ضيف عنصر في مصفوفة `DAYS` (kicker + html + foot)، وبعدين:

```bash
node -e "..."   # أو استخدم سكربت الرندر في السجل
```

الرندر بيتم بـ Playwright على ١٠٨٠×١٩٢٠:

```bash
npx playwright screenshot --viewport-size=1080,1920 "file://$PWD/story.html?d=7" day-8.png
```

## قاعدة
**كل يوم صورة مختلفة** — مفيش إعادة استخدام لنفس التكوين. بدّل بين التكوينات الثلاثة:
سطر كبير · رقم ضخم · قائمة ٣ نقاط.
